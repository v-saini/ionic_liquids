# An interpretable molecular descriptor-based machine learning approach for predicting the empirical polarity of ionic liquids 

💡 This repository contains the following files.

 - data_final - Type, ID, Name, Cation smiles, Anion smiles, ET30 and 168 descriptors

 - predictions_train_nn.xlsx - Train set predictions on the NN model (tuned) trained on 15 descriptors

 - predictions_val_nn.xlsx - Validation set predictions on the NN model (tuned) trained on 15 descriptors

 - predictions_test_nn.xlsx - Test predictions on the NN model (tuned) trained on 15 descriptors

 - train_ids - Pickel file containing train IDs

 - val_ids - Pickel file containing val IDs

 - test_ids - Pickel file containing test IDs

 - model_168.ipynb - Python code for model screening using 168 descriptors

 - model_15.ipynb - Python code for model screening using 15 descriptors

 - hyper_p_tuning.ipynb - Hyperparameter tuning for NN model and final model

 - nn_tuned.keras - Saved NN model with tuned parameters
   
 - imp.xlsx - List of important descriptors as identified using ET-based feature importance algorithm
